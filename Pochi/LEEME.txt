POCHI - DISCORD DIRECTO (SIN SUPABASE)

Esta versión NO usa Supabase.
Cuando una persona pulsa "clic" para entrar al perfil, el navegador manda un embed directamente al webhook de Discord.

ARCHIVOS IMPORTANTES
- index.html: página principal.
- app-config.js: contiene la URL del webhook.
- visit-logger.js: obtiene los datos técnicos y manda el aviso a Discord.

PARA PUBLICAR
1. Reemplaza en GitHub Pages los archivos viejos de la carpeta Pochi por estos.
2. Espera a que GitHub Pages termine el despliegue.
3. Abre la web, pulsa "clic" y revisa el canal de Discord.
4. Si GitHub muestra una versión vieja, usa Ctrl+F5.

IMPORTANTE DE SEGURIDAD
GitHub Pages solo sirve archivos públicos. Por eso, en esta versión directa el webhook puede verse desde el navegador.
Si alguien copia el webhook puede usarlo para enviar mensajes al canal. Para ocultarlo hace falta un backend/proxy (por ejemplo Cloudflare Worker, Vercel Function, etc.).

Si regeneras el webhook en Discord, cambia discordWebhookUrl dentro de app-config.js.
